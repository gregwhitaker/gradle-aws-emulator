include::_partials/resource-links.adoc[]

Custom resource tasks default to a managed instance that is cleaned up when the build finishes. Module convenience tasks use the persistent development instance. See xref:lifecycle.adoc#provision-development-resources[development resource tasks] to keep resources available between builds.

Use xref:scenarios.adoc#resource-sets[reusable resource sets] to share definitions across tests, local applications, and development scenarios. The xref:cloudformation.adoc[CloudFormation guide] covers provisioning from local templates.
