= Secrets Manager
include::_partials/attributes.adoc[]
:description: Create, inspect, and delete Secrets Manager secrets and load local secret fixtures.

Provision local application secrets before tests, load JSON fixtures, and manage development secrets. Task types live in `io.github.gregwhitaker.awsemulator.aws.secretsmanager`.

toc::[]

== Provision before tests

=== Kotlin DSL

[source,kotlin]
----
import io.github.gregwhitaker.awsemulator.aws.secretsmanager.PutSecretsTask

plugins {
    java
    id("io.github.gregwhitaker.aws-emulator")
}

val secrets = tasks.register<PutSecretsTask>("seedSecrets") {
    fixtures.set(layout.projectDirectory.file("fixtures/secrets.json"))
}
val tests = tasks.named<Test>("test") { dependsOn(secrets) }
awsEmulator { useWith(tests) }
----

=== Groovy DSL

[source,groovy]
----
import io.github.gregwhitaker.awsemulator.aws.secretsmanager.PutSecretsTask

plugins {
    id 'java'
    id 'io.github.gregwhitaker.aws-emulator'

def secrets = tasks.register('seedSecrets', PutSecretsTask) {
    fixtures.set(layout.projectDirectory.file('fixtures/secrets.json'))
}
def tests = tasks.named('test') { dependsOn(secrets) }
awsEmulator { useWith(tests) }
----

== Task properties

[cols="1,2",options="header"]
|===
|Task type |Configuration
|`PutSecretTask` |`secretName`, `value` string, optional `keyId`, `overwrite` (default `false`)
|`PutSecretsTask` |`fixtures` JSON file, `overwrite`
|`ListSecretsTask` |Lists secret names, including secrets scheduled for deletion
|`DescribeSecretTask` |`secretName`; prints ARN and deletion date without the value
|`DeleteSecretsTask` |Explicit `names`, `recoveryWindowInDays` (7–30; default 30), `force` (default `false`)
|===

== Fixture format

.fixtures/secrets.json
[source,json]
----
[
  {"name":"app/database","value":"{\"username\":\"local\",\"password\":\"local-only\"}"}
]
----

Every entry requires string `name` and `value`, with an optional `keyId`. Declare a dependency on xref:kms.adoc#provision-before-tests[`CreateKmsKeyTask`] when referring to a custom key alias. Secret strings allow up to 65536 UTF-8 bytes. Binary secrets, secret rotation, and version-stage management are outside these task types.

== Reuse and overwrite behavior

Identical values are reused without creating new versions. Different values require `overwrite=true`. Explicit key identifiers are compared with the identifier reported by the service; consistently use the same key ID or alias. Provisioning never restores a secret scheduled for deletion. Metadata commands and provisioning errors omit values; applications read values through their SDKs.

== Development commands

[source,shell]
----
./gradlew listSecrets
./gradlew describeSecret --secretName=app/database
./gradlew deleteSecrets --names=app/database
----

Select names for deletion with repeated `--names` options. Deletion defaults to a 30-day recovery window; `recoveryWindowInDays` accepts 7–30 days, and `--force` requests asynchronous deletion without recovery. Stopping a managed emulator discards its entire in-memory state immediately.

== Runnable example

[source,shell]
----
./gradlew -p examples/services verifyServices --configuration-cache
----

The example seeds a database secret from JSON and reads its value using AWS SDK for Java v2. Run the command twice to check configuration-cache reuse against a fresh managed emulator. `-PfailExample=true` deliberately fails the application test to demonstrate cleanup. See link:{repo-url}/tree/main/examples/services[the runnable example] for its complete setup and persistent development commands.
