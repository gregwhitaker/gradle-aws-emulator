[[a-small-addition-to-your-build]]
.build.gradle.kts
[source,kotlin]
----
plugins {
    java
    id("io.github.gregwhitaker.aws-emulator")
}

awsEmulator {
    useWith(tasks.named<Test>("integrationTest"))
}
----

== Run The Example

From this repository's root, run the included example:

[.quickstart-command]
--
.Terminal
[source,shell]
----
./gradlew -p examples/basic integrationTest --configuration-cache
----
--

++++
<div class="runtime-flow" aria-label="What the example does">
  <div class="runtime-step"><span class="step-number">01</span><div><strong>Provision Resources</strong><span>Create S3 buckets and SQS queues in a fresh emulator.</span></div></div>
  <div class="runtime-step"><span class="step-number">02</span><div><strong>Send SDK Requests</strong><span>Run signed AWS SDK requests against your local resources.</span></div></div>

The first run builds the emulator image; later runs reuse it. Run the command again to check configuration-cache reuse. Follow the xref:getting-started.adoc[getting started guide] to add the plugin to your own application.

[[choose-the-right-lifetime]]
Run tests against a xref:testing.adoc[fresh emulator] or keep one running for xref:lifecycle.adoc[local development].

Keep your application's AWS SDK and test dependencies, and see xref:connections.adoc[SDK connection setup] for endpoints and TLS. Applying the plugin alone does not start Docker; tasks opt in explicitly.

== Requirements

Use *Java 17+*, *Gradle 8.14+*, and a local *Docker engine running Linux containers*. The first run builds an image from AWS's pinned `{emulator-version}` package. Linux AMD64 and ARM64 are supported; subsequent runs reuse the image.

Docker integration is verified on Linux AMD64 and ARM64. Windows runs the Docker-free verification suite; Docker integration on Windows has not been verified.

For ports, images, regions, and timeouts, see xref:configuration.adoc[configuration]. See https://github.com/aws/aws-emulator[AWS Emulator] for the upstream project, or xref:troubleshooting.adoc[troubleshooting] if something isn't working.
